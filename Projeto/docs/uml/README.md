# SentinelTrade — Diagramas UML em Draw.io

Esta pasta reúne os diagramas UML editáveis da continuação do projeto SentinelTrade.

## Como abrir e editar

1. Acesse https://app.diagrams.net/.
2. Selecione **Ficheiro > Abrir de > Dispositivo**.
3. Escolha o arquivo `.drawio` desejado.
4. Edite os elementos diretamente na tela e salve com `Ctrl + S`.

Os diagramas foram construídos com elementos nativos do Draw.io (formas, textos, classes, linhas e conectores), permitindo editar cada parte separadamente.
